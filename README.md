### Projeto 1 — Caixa de mercado no console

Crie um programa que registre produtos de uma compra, calcule o total e aplique regras de desconto.

**Requisitos:**

- Ler nome, preço e quantidade dos produtos.
- Repetir o cadastro até o usuário escolher finalizar.
- Calcular subtotal, desconto e valor final.
- Validar valores inválidos usando condicionais.
- Separar os cálculos em métodos.
